# ☕ Coffee Shop

یک وب‌سایت فروشگاه قهوه با طراحی `Responsive` که با استفاده از `React` و تکنولوژی‌های مدرن `Front-End` توسعه داده شده است.

> 🚧 **وضعیت پروژه:** این پروژه در حال توسعه و به‌روزرسانی است و قابلیت‌های جدید به مرور به آن اضافه خواهند شد.

**🔗 نسخه آنلاین پروژه:**  
https://seyedmahdim4-beep.github.io/coffee/

---

## 📌 معرفی پروژه

این پروژه با هدف پیاده‌سازی یک رابط کاربری مدرن برای یک فروشگاه آنلاین قهوه طراحی و توسعه داده شده است.

تمرکز اصلی پروژه روی ایجاد یک رابط کاربری `Responsive`، ساختاری `Component-Based` و قابل توسعه بوده است.

در توسعه پروژه تلاش شده بخش‌های مختلف رابط کاربری به صورت کامپوننت‌های مستقل پیاده‌سازی شوند تا ساختار پروژه خوانا، قابل نگهداری و قابل توسعه باشد.

---

## ✨ امکانات فعلی

- طراحی کاملاً `Responsive`
- صفحه اصلی فروشگاه
- نمایش محصولات قهوه
- نمایش قیمت و تخفیف محصولات
- نمایش امتیاز محصولات
- بخش مقالات و وبلاگ
- اسلایدر محصولات با `Swiper`
- طراحی رابط کاربری با `Tailwind CSS`
- استفاده از کامپوننت‌های قابل استفاده مجدد در `React`
- مدیریت اطلاعات محصولات و مقالات به صورت `Data-driven`
- مدیریت مسیر `Assets` برای محیط `Production`
- انتشار پروژه با `GitHub Pages`

---

## 🛒 سبد خرید

بخش مربوط به رابط کاربری سبد خرید در پروژه در نظر گرفته شده است.

پیاده‌سازی و تکمیل **منطق سبد خرید** از جمله مدیریت محصولات، تعداد کالاها، محاسبه قیمت و تعاملات مربوط به سبد خرید، در به‌روزرسانی‌های آینده پروژه انجام خواهد شد.

این پروژه همچنان در حال توسعه است و امکانات جدید به مرور به آن اضافه می‌شوند.

---

## 🛠️ تکنولوژی‌های استفاده‌شده

| تکنولوژی | کاربرد |
|---|---|
| `React` | ساخت رابط کاربری و کامپوننت‌ها |
| `Vite` | ابزار توسعه و `Build` پروژه |
| `JavaScript` | پیاده‌سازی منطق و تعاملات |
| `Tailwind CSS` | طراحی رابط کاربری و `Responsive Design` |
| `Swiper` | ایجاد اسلایدر |
| `Git` | مدیریت نسخه‌ها |
| `GitHub` | مدیریت و میزبانی Repository |
| `GitHub Pages` | انتشار نسخه آنلاین |
