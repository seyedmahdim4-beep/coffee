# ☕ Coffee Shop

یک وب‌سایت فروشگاه قهوه با طراحی `Responsive` که با استفاده از `React` و تکنولوژی‌های مدرن `Front-End` توسعه داده شده است.

> 🚧 **وضعیت پروژه:** این پروژه در حال توسعه و به‌روزرسانی است و قابلیت‌های جدید به مرور به آن اضافه خواهند شد.

**🔗 نسخه آنلاین پروژه:**
https://seyedmahdim4-beep.github.io/coffee/

---

## 📌 معرفی پروژه

این پروژه با هدف پیاده‌سازی یک رابط کاربری مدرن برای یک فروشگاه آنلاین قهوه طراحی و توسعه داده شده است.

تمرکز اصلی پروژه روی ایجاد یک رابط کاربری `Responsive`، ساختاری `Component-Based` و قابل توسعه بوده است.

در توسعه پروژه تلاش شده بخش‌های مختلف رابط کاربری به صورت کامپوننت‌های مستقل پیاده‌سازی شوند تا ساختار پروژه خوانا، قابل نگهداری و قابل توسعه باشد.

## 📂 ساختار پروژه

```text
coffee/
├── public/
│   └── image/
│
├── src/
│   ├── components/
│   ├── data/
│   ├── App.jsx
│   └── main.jsx
│
├── docs/
├── index.html
├── package.json
├── package-lock.json
├── vite.config.js
└── eslint.config.js
```

### توضیح بخش‌های اصلی

**`src/`**
کدهای اصلی `React` پروژه در این بخش قرار دارند.

**`src/components/`**
کامپوننت‌های قابل استفاده مجدد رابط کاربری.

**`src/data/`**
اطلاعات مربوط به محصولات و مقالات پروژه.

**`public/`**
فایل‌های استاتیک مانند تصاویر پروژه.

**`docs/`**
خروجی `Production Build` که برای انتشار پروژه در `GitHub Pages` استفاده می‌شود.

## 🚀 اجرای پروژه

ابتدا Repository را دریافت کنید:

```bash
git clone https://github.com/seyedmahdim4-beep/coffee.git
```

وارد پوشه پروژه شوید:

```bash
cd coffee
```

سپس وابستگی‌های پروژه را نصب کنید:

```bash
npm install
```

برای اجرای پروژه در محیط `Development`:

```bash
npm run dev
```

برای ساخت نسخه `Production`:

```bash
npm run build
```
