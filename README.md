# ☕ Coffee Shop

یک وب‌سایت فروشگاه آنلاین قهوه با طراحی مدرن و کاملاً `Responsive` که با استفاده از `React` و ابزارهای مدرن توسعهٔ Front-End پیاده‌سازی شده است.

> 🚧 **وضعیت پروژه:** این پروژه در حال توسعه است و با هدف تمرین و پیاده‌سازی مفاهیم کاربردی توسعهٔ وب، به‌مرور در حال گسترش و بهبود است.

**🔗 نسخه آنلاین پروژه:**

https://seyedmahdim4-beep.github.io/coffee/

---

## 📌 معرفی پروژه

پروژهٔ Coffee Shop یک فروشگاه آنلاین قهوه است که با هدف شبیه‌سازی تجربهٔ خرید اینترنتی و پیاده‌سازی بخش‌های مختلف یک فروشگاه آنلاین طراحی و توسعه داده شده است.

تمرکز اصلی پروژه بر طراحی رابط کاربری مدرن، ساختار کامپوننت‌محور، مدیریت داده‌ها و پیاده‌سازی تعاملات موردنیاز یک فروشگاه اینترنتی بوده است.

در این پروژه تلاش شده بخش‌های مختلف به‌صورت کامپوننت‌های مستقل و قابل استفادهٔ مجدد پیاده‌سازی شوند تا توسعه، نگهداری و گسترش قابلیت‌های آن ساده‌تر باشد.

---

## ✨ امکانات و قابلیت‌ها

- طراحی کاملاً `Responsive` و سازگار با دستگاه‌های مختلف
- صفحهٔ اصلی فروشگاه
- نمایش محصولات قهوه همراه با تصاویر و جزئیات
- نمایش قیمت، تخفیف و امتیاز محصولات
- بخش مقالات و وبلاگ
- اسلایدر محصولات با استفاده از `Swiper`
- پیاده‌سازی سبد خرید
- افزودن و حذف محصولات از سبد خرید
- مدیریت تعداد محصولات در سبد خرید
- محاسبهٔ قیمت نهایی سفارش
- پیاده‌سازی فرایند ثبت سفارش
- طراحی رابط کاربری درگاه پرداخت نمایشی
- مسیریابی بین صفحات با استفاده از `React Router`
- ساختار کامپوننت‌محور و استفادهٔ مجدد از اجزای رابط کاربری
- مدیریت اطلاعات محصولات و مقالات به‌صورت `Data-driven`
- مدیریت مسیر تصاویر و Assets برای محیط `Production`
- آماده‌سازی و انتشار نسخهٔ نهایی با `GitHub Pages`

## 🛒 سبد خرید و فرایند ثبت سفارش

در این پروژه بخش سبد خرید با هدف شبیه‌سازی فرایند خرید در یک فروشگاه اینترنتی پیاده‌سازی شده است.

قابلیت‌های این بخش شامل موارد زیر است:

- افزودن محصولات به سبد خرید
- حذف محصولات از سبد خرید
- افزایش و کاهش تعداد کالاها
- محاسبهٔ تعداد کل محصولات
- محاسبهٔ قیمت نهایی سفارش
- نمایش خلاصهٔ سفارش پیش از پرداخت

همچنین برای تکمیل فرایند خرید، یک رابط کاربری برای درگاه پرداخت طراحی و پیاده‌سازی شده است.

> ⚠️ **توجه:** درگاه پرداخت این پروژه صرفاً نمایشی است و به هیچ سرویس بانکی یا درگاه پرداخت واقعی متصل نیست. این بخش با هدف تمرین طراحی و پیاده‌سازی مراحل پرداخت توسعه داده شده است.

## 🧭 مسیریابی صفحات

برای مدیریت مسیرها و جابه‌جایی بین صفحات مختلف پروژه از `React Router` استفاده شده است.

این ساختار امکان دسترسی به صفحات مختلف فروشگاه و ایجاد تجربهٔ کاربری منسجم‌تری را فراهم می‌کند.

---

## 🛠️ تکنولوژی‌های استفاده‌شده

| تکنولوژی | کاربرد |
|---|---|
| `React` | ساخت رابط کاربری و کامپوننت‌ها |
| `Vite` | ابزار توسعه و Build پروژه |
| `JavaScript` | پیاده‌سازی منطق و تعاملات |
| `React Router` | مدیریت مسیرها و مسیریابی صفحات |
| `Tailwind CSS` | طراحی رابط کاربری و Responsive Design |
| `Swiper` | ایجاد اسلایدر محصولات |
| `Git` | مدیریت نسخه‌ها |
| `GitHub` | مدیریت مخزن پروژه |
| `GitHub Pages` | انتشار نسخه آنلاین |
